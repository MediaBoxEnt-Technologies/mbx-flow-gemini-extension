# MBX Flow for Gemini CLI

Connect [Gemini CLI](https://github.com/google-gemini/gemini-cli) to [MBX Flow](https://mbxflow.com), the social media publishing tool from MediaBoxEnt Technologies.

Ask Gemini things like:
- "What do I have scheduled for next week?"
- "Write a draft for Instagram and Facebook about my new single."
- "Schedule this post for Friday at 6 pm on all my accounts."

Nothing is published right away and nothing is deleted. Publishing now stays with you inside MBX Flow.

## Install

```bash
gemini extensions install https://github.com/MediaBoxEnt-Technologies/mbx-flow-gemini-extension
```

The first time Gemini uses MBX Flow, your browser opens the MBX Flow sign-in page. Approve the connection for your workspace and you are done. To disconnect, remove the app in MBX Flow under Settings, Integrations, Connected apps, or run `gemini extensions uninstall mbx-flow`.

## Requirements
- An [MBX Flow](https://mbxflow.com) account on the Pro plan or higher.
- Gemini CLI.
